Modello per codice, JSON e agenti AI.

3.02 GB TOTALI

I quattro Context Binaries

PART 1 / 4 743 MB Embedding + primi layer
PART 2 / 4 632 MB Layer intermedi
PART 3 / 4 632 MB Layer intermedi
PART 4 / 4 1011 MB Ultimi layer + LM Head

07 / KNOWLEDGE BASE

Glossario tecnico

Le tecnologie e gli acronimi principali del progetto.

SoC

System on Chip: integra CPU, GPU e cDSP.

HTP

Hexagon Tensor Processor: acceleratore neurale Qualcomm.

cDSP

Compute Digital Signal Processor dedicato al calcolo parallelo.

HMX

Unità matriciale Hexagon per le operazioni tensoriali.

HVX

Unità vettoriale Hexagon.

VTCM

Memoria SRAM interna all'HTP.

UMA

Unified Memory Architecture: memoria fisica condivisa.

FastRPC

Comunicazione tra ARM e cDSP.

Stub / Skel

Proxy CPU e componente eseguito sul DSP.

QAIRT

Qualcomm AI Runtime SDK.

QNN

Qualcomm AI Engine Direct.

Genie

Motore di inferenza generativa basato su QNN.

AIMET

Toolkit Qualcomm per quantizzazione e calibrazione.

W4A16

Pesi INT4 e attivazioni FP16/INT16.

RoPE

Rotary Position Embedding.

KV-Cache

Memorizzazione di Key e Value dell'Attention.

TTFT

Time To First Token.

SSE

Server-Sent Events per lo streaming HTTP.

AOT

Ahead-Of-Time: compilazione anticipata.

DCVS

Dynamic Clock and Voltage Scaling.

DMA-BUF

Meccanismo Linux per la condivisione di buffer.

ChatML

Formato strutturato dei messaggi del modello.
